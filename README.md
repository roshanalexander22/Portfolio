# Roshan Alexander — Portfolio Website

A futuristic, high-performance developer portfolio featuring 3D interactive graphics, sleek typography, dynamic particle systems, holographic tilt physics, and modern cyber-aesthetic design.

🌐 **Live Demo:** [Deployable on Vercel](https://vercel.com)

---

## ⚡ Tech Stack

- **Framework:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **3D Graphics:** [Three.js](https://threejs.org/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Audio Synthesis:** Web Audio API (zero external asset dependencies)
- **Icons:** [Lucide React](https://lucide.dev/) + Custom SVGs
- **Deployment:** [Vercel](https://vercel.com/)

---

## 🚀 Features & Finishing Touches

- **Interactive 3D Particle Cloud:** 10,000+ interactive Three.js particles reacting dynamically to mouse cursor physics and velocity.
- **Holographic 3D Tilt Card:** Smooth spring-physics tilt on mouse move over the hero photograph.
- **Precision Cyber Cursor:** Lagging glowing ring with magnetic hover states over interactive elements.
- **Interactive Cyber Terminal / Command Palette:** Toggle with `⌘K` or the `CMD` button to run quick terminal commands (`projects`, `skills`, `contact`, `phone`, `instagram`, etc.).
- **Synthesized UI Audio (FX Toggle):** Ultra-subtle cybernetic audio feedback generated on the fly via the Web Audio API with a one-click mute toggle.
- **Floating Social Dock:** Quick access to GitHub, LinkedIn, Instagram, WhatsApp, Phone, and Email.
- **One-Click Clipboard & Toast:** Instant clipboard copying for phone (+91 9656271863) and email with sleek HUD toast alerts.
- **Live IST Clock HUD:** Real-time Asia/Kolkata clock displayed in the header navigation.
- **Dynamic Text Scrambler:** Cyberpunk-style letter-randomizing text reveal animations.
- **Interactive Info Drawer:** Full-screen glassmorphic overlay showcasing projects, education, technical skills, direct contact channels, and social links.

## 🛠️ Local Development

### 1. Clone the repository:
```bash
git clone https://github.com/roshanalexander22/Portfolio.git
cd Portfolio
```

### 2. Install dependencies:
```bash
npm install
```

### 3. Start development server:
```bash
npm run dev
```

### 4. Build for production:
```bash
npm run build
```
