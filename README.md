# Roshan Alexander — Portfolio Website

A futuristic, high-performance developer portfolio featuring 3D interactive graphics, sleek typography, dynamic particle systems, and modern cyber-aesthetic design.

🌐 **Live Demo:** [Deployable on Vercel](https://vercel.com)

---

## ⚡ Tech Stack

- **Framework:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **3D Graphics:** [Three.js](https://threejs.org/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/) + Custom SVGs
- **Deployment:** [Vercel](https://vercel.com/)

---

## 🚀 Features

- **Interactive 3D Particle Cloud:** 10,000+ interactive Three.js particles reacting dynamically to mouse cursor physics and velocity.
- **Dynamic Text Scrambler:** Cyberpunk-style letter-randomizing text reveal animations.
- **Interactive Info Drawer:** Full-screen glassmorphic overlay showcasing projects, education, technical skills, and social links.
- **Curated Visual Palette:** Deep Space Blue (`#030014`), Electric Acid Lime (`#CCFF00`), and subtle radial gradients.
- **Responsive Layout:** Optimized for desktop and mobile viewports with fluid typography.

---

## 🛠️ Local Development

### 1. Clone the repository:
```bash
git clone https://github.com/roshanalexander22/Portfolio.git
cd Portfolio
```

### 2. Install dependencies:
```bash
npm install
```

### 3. Start development server:
```bash
npm run dev
```

### 4. Build for production:
```bash
npm run build
```
